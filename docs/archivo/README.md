# Archivo

Borradores del proyecto base fuera de la zona principal (El Vendrell y Baix Penedès). Con ADR-001 quedan dentro
del radio operativo de 50 km, pero no se publican ni se listan en el sitio (decisión D6). Se conservan como fuente: `pladur-conductos-sitges.md` respalda dos puntos del alcance
del servicio de aislamiento acústico (sistemas multicapa de placa de yeso y lana de roca de alta densidad).
